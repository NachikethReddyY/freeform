## Existing and previously proven

- **Canvas base:** Native shapes, free draw, text, notes, arrows, frames, pan/zoom and edit history through the installed tldraw editor; local sync and uploaded media persistence survived host and isolated Docker restart tests. FreeForm customizes Excalifont, colors, strokes and an arrow curve while keeping native shape records (`../client/pages/Room.tsx:47-75,182-213,262-307`; `../client/editor/excalidrawShapes/README.md:1-44`; `../docs/FEATURE_CHECKLIST.md:9-13`).
- **Board organization:** Create/open, inline rename, search by name, collections, two-board bulk move, Copy link, recoverable Trash and browser-local previews have reported browser proof, including a 720px selected state (`../README.md:19`; `../docs/FEATURE_CHECKLIST.md:16-17`; `../client/features/boards/BoardDashboard.tsx:193-249`).
- **Editable flowcharts:** A bounded Mermaid flowchart subset previews, inserts and binds native tldraw shapes; a connected Codex/Pi session can read a bounded board summary and queue a proposal for browser review before insertion (`../mcp/README.md:44-53,90-93`; `../client/features/diagrams/native.ts:31-99`; `../docs/FEATURE_CHECKLIST.md:35-45`).
- **Basic slide presentation:** Top-level frames are slides in explicit saved order, with spatial order as the fallback. Start/exit, keyboard navigation, fit, fullscreen fallback and restoration have focused tests and reported browser proof (`../client/features/presentation/presentation.tsx:5-29,68-91`; `../docs/FEATURE_CHECKLIST.md:55-61`).
- **Tool discovery:** A Cmd/Ctrl+K command palette searches a curated subset of native actions/tools; prior browser verification covers open, filter and run (`../client/features/commandPalette/commands.ts:3-22`; `../client/features/commandPalette/CommandPalette.tsx:9-25,65-100`; `../docs/FEATURE_CHECKLIST.md:18-19`).
- **Faster diagram construction:** Selecting one supported node exposes four icon controls that add an editable connected rectangle with native arrow binding. Five native-record starters and saved personal blocks are available in Diagrams; reported browser checks cover a starter and personal-block save, reload and reinsertion (`../client/features/diagrams/connectedNodeControls.tsx:13-47`; `../client/features/diagrams/library/templates.ts:3-53`; `../client/features/diagrams/library/library.ts:70-88,152-153`; local browser screenshot `connected-node-panel.png` (not distributed)).
- **Portable files:** Board Files downloads a native JSON document and current-page/selection PNG or SVG; import validates before creating a new local room. The browser pass checked native JSON and `.tldr` imports, two pages, an embedded PNG after reload, all page/selection PNG/SVG downloads, transparency, draw-font SVG embedding, and invalid import without source-board mutation. A bounded Excalidraw fixture converted three elements, skipped one image and exported a parseable three-element/one-binding file (`../client/features/portability/README.md:1-7`; `../client/features/portability/excalidraw/README.md:3-15`; local browser screenshot `board-files-matrix-import-media-reload.png` (not distributed)).
- **Slide organization and compact controls:** Slides previews, renames, jumps and reorders top-level frames; browser checks covered reorder/undo/reload/fullscreen/Escape/rename cancel. The 720px toolbar and 1016px selected card were checked without overlap; independent geometry Stroke/Background presets, custom picker, transparent fill, SVG/PNG and reload passed on a disposable rounded rectangle (`../client/editor/excalidrawShapes/FreeformBackgroundPicker.tsx`; local screenshot `independent-colors-app.jpg`, not distributed). S→XL visibly changed a selected rectangle label and remained after reload. Excalifont bold is heavier in the editor and SVG via a text-shadow workaround; PNG/thumbnail proof and a wider responsive/action matrix remain open.

## Excalidraw parity and source reuse

The local Excalidraw checkout's [README at the inspected revision](https://github.com/excalidraw/excalidraw/blob/4850bf336fe0a8501af49d84deebc7fb56357cc2/README.md) lists its **free editor** surface: infinite canvas, hand-drawn style, dark mode, images, shape libraries, localization, PNG/SVG/clipboard and `.excalidraw` export, core shapes, binding, undo and zoom (sibling `README.md:52-69`). Its hosted app additionally advertises PWA/offline, encrypted real-time collaboration, local-first save and read-only share links (sibling `README.md:71-81`). [Excalidraw Plus](https://plus.excalidraw.com/) advertises cloud workspaces, advanced sharing, live presentations, extended collaboration and upgraded generative AI; those paid-service features are **not** provided by the local open-source checkout. This comparison is feature-level and does not imply FreeForm includes those features.

FreeForm covers much of the drawing base through tldraw, adds a small personal block library and bounded `.excalidraw` interchange, and has browser-checked native JSON/PNG/SVG file actions. Excalidraw parity remains partial: this is not its full library ecosystem or file fidelity, and localization, PWA/offline, encrypted sharing, read-only links, in-app AI chat, and Plus-grade cloud workspace/live collaboration remain absent (`../README.md:23-35`; `../client/features/portability/excalidraw/README.md:11-15`).

**Copying boundary:** The local Excalidraw checkout is [MIT licensed](https://github.com/excalidraw/excalidraw/blob/4850bf336fe0a8501af49d84deebc7fb56357cc2/LICENSE); copied source must retain its copyright and license notice (sibling `LICENSE:1-20`). The current interchange adapter references its public v2 file format and says no Excalidraw source was copied (`../client/features/portability/excalidraw/README.md:15`). FreeForm's app `LICENSE.md` is MIT (`../LICENSE.md:1-9`), but installed `tldraw@5.4.2` points to the [tldraw license](https://github.com/tldraw/tldraw/blob/main/LICENSE.md), not MIT (installed tldraw 5.4.2 package `package.json:1-7` and `LICENSE.md:1`; package source is not distributed here). Connected-node creation cites an official tldraw example as a source of its native shape/binding flow (`../client/features/diagrams/connectedNode.ts:9-10`). The SDK works in development; [production requires a valid trial, hobby or commercial key](https://tldraw.dev/sdk-features/license-key), with the hobby watermark. Keep SDK code under its own license; Excalidraw Plus service features are not donor source.
