FreeForm: progress and UX evidence

FreeForm now combines tldraw’s native editable canvas with a quieter Excalidraw-inspired shell, faster diagram construction, file exchange, slide organization and board search. The screenshots below show the current interface. This is a working local product with specific proven flows, not full Excalidraw or Excalidraw Plus parity.

What changed

Editor

Compact top tools, a contextual left panel, a 4×3 palette with a rainbow custom color entry, icon actions, independent stroke width/style, sloppiness, sharp/rounded edges, and a rectangle Size control that changes label size. Arrow curves retain native bindings.

Diagramming

Four directional Connect actions, five editable starters, browser-local personal blocks, Mermaid preview/import, and a review-before-insert MCP proposal loop. Flowchart branch labels now clear their arrows.

Boards and navigation

Dashboard previews, collections, name search, inline rename, Select, recoverable Trash, anchored card actions and a 720px layout. Board URLs now survive direct navigation and hard reload. The new top-right search finds board content across pages.

Files and slides

Native board JSON and .tldr import into separate rooms, PNG/SVG page or selection export with checked transparency and embedded draw font, bounded Excalidraw v2 import/export with omission reports, and a Slides panel for frame preview, order, rename and jump. Present mode retains keyboard and fullscreen controls.

Open UX and product limits

  • Finish custom color and independent Stroke/Background color checks, theme/mobile combinations, and PNG/thumbnail proof for Excalifont bold; selected-shape icon actions now have browser proof.
  • Measure large-board search and native exchange with linked media, other fonts and large files; Excalidraw interchange intentionally skips unsupported images, frames, freehand and complex connectors.
  • Provide speaker notes and export only after the compact Slides interaction remains clear. In-app AI chat is not configured because no model provider has been selected; the existing MCP proposal flow still requires explicit review before insertion.
  • Obtain a valid tldraw license key before public production deployment. Current verification is for the local app.

Scope note. The source idea brief covers 44 themes and 749 list ideas. The feature map records where FreeForm has a bounded useful slice and where dedicated tools are absent. This report does not convert a generic drawable canvas into a claim of full feature parity.

Verification and source trail

The integrated production build passed. Focused suites passed for boards (19), diagrams (26), slides (14), palette (3), search (4), routing (2), and the 25-case combined portability/style/search/routing run. The MCP smoke completed ten protocol checks without a model call. The build still warns that the main JavaScript chunk exceeds 500 KB.

How to reproduce the local checks

Run pnpm build, pnpm test:boards, pnpm test:diagrams, pnpm test:presentation, pnpm test:palette, and pnpm test:mcp. The focused portability, shape, search and route tests are listed in the repository checklist. Use disposable boards for browser checks and preserve the local Worker state.
