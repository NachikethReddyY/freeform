How the new paths work

Diagram with native shapes

Insert a technical starter or use Cmd+K to connect a bound neighbor. Type its label directly. Select an eligible graph to arrange it horizontally, vertically or as a tree; copied Mermaid describes that selected subset. Full-board exchange remains native .tldr.

Paste with review

Plain-text Markdown, JSON, fenced code and safe HTTP URLs open Preview and Source. Add creates an editable native geo card with the exact original source in metadata. The preview can show formatting or syntax color; all canvas inline marks are flattened to avoid unreadable overlap.

Keep local state

The signed-in owner catalog reconciles the browser cache with local SQLite, preserving board IDs and Trash tombstones. Dashboard indicates saving or unavailable sync. Room documents, assets, previews and personal blocks still use their separate stores.

Present and collaborate

Frames become slides with right-aligned controls and light/dark stages. A fading laser trail is covered in focused tests. A separate two-client local integration sequence exercised shared shapes and an asset through WebSocket sync and R2; browser cursor experience is still open.
