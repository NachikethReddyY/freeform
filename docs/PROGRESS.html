FreeForm: progress and UX evidence

FreeForm now combines tldraw’s native editable canvas with a quieter Excalidraw-inspired shell, faster diagram construction, file exchange, slide organization and board search. The screenshots below show the current interface. This is a working local product with specific proven flows, not full Excalidraw or Excalidraw Plus parity.

What changed

Editor

Compact top tools with native tool lock, a contextual left panel, a 4×3 stroke palette with a rainbow custom color entry, an independent Background palette shown for the geometry tool or geometry selection, icon actions, stroke width/style, sloppiness, sharp/rounded edges, and a rectangle Size control that changes label size. Cartoonist now changes Solid, Dashed and Dotted rectangle outlines and dashed/dotted native straight lines while retaining their stroke patterns. The visible line bends remain selectable. Arrow curves retain native bindings.

Diagramming

Four directional Connect actions, five editable starters, browser-local personal blocks, Mermaid preview/import, and a review-before-insert MCP proposal loop. Connect now focuses the new native label for immediate typing. Flowchart branch labels clear their arrows. Eligible connected nodes offer compact Arrange with bound-arrow preservation, space around unrelated shapes and one-step undo. The Sequence starter has four time-ordered messages across three dashed, headless lifelines; its invisible bound anchors now move with the selected diagram without drawing blue outlines.

Boards and navigation

Dashboard previews, collections, name search, inline rename, Select with bulk move, recoverable Trash, anchored card actions and a 720px layout. Board URLs and new native pages survive direct navigation and hard reload in a visible browser. Socket recovery now protects hibernated and replaced sessions. The top-right search finds board content across pages and supports ArrowUp/Down and Enter.

Files and slides

Native board JSON and .tldr import into separate rooms, PNG/SVG page or selection export with checked transparency and embedded draw font, bounded Excalidraw v2 import/export with omission reports, and a Slides panel for frame preview, order, rename and jump. Present mode retains keyboard and fullscreen controls.

Open UX and product limits

  • Check more theme/mobile combinations. Selected Excalifont bold PNG export showed visible weight contrast; its text-only dashboard thumbnail now renders after reload. Selected-shape icon actions and geometry color export have browser proof.
  • Keep browser tabs visible during automated persistence checks. Safari reported hidden with zero animation frames even when its window was raised, so tldraw queued writes there. The visible Zen session saved both new pages and their shapes to the room API.
  • Measure large-board search and native exchange with linked media, other fonts and large files; Excalidraw interchange intentionally skips unsupported images, frames, freehand and complex connectors.
  • Provide speaker notes and export only after the compact Slides interaction remains clear. In-app AI chat is not configured because no model provider has been selected; the existing MCP proposal flow still requires explicit review before insertion.
  • Obtain a valid tldraw license key before public production deployment. Current verification is for the local app.

Scope note. The source idea brief covers 44 themes and 749 list ideas. The feature map records where FreeForm has a bounded useful slice and where dedicated tools are absent. This report does not convert a generic drawable canvas into a claim of full feature parity.

Verification and source trail

The integrated production build passed. Focused suites passed for boards (20), diagrams (41), slides (14), palette (3), socket recovery (3), and the 36-case combined color/style/portability/search/routing run. The MCP smoke completed ten protocol checks without a model call. The build still warns that the main JavaScript chunk exceeds 500 KB.

How to reproduce the local checks

Run pnpm build, pnpm test:boards, pnpm test:diagrams, pnpm test:presentation, pnpm test:palette, and pnpm test:mcp. The focused portability, shape, search and route tests are listed in the repository checklist. Use disposable boards for browser checks and preserve the local Worker state.
