The new review flow

The chat panel accepts a local Ollama endpoint on loopback or a deliberately configured OpenAI-compatible HTTPS endpoint. A model reply can be plain text through Ask or a validated diagram through Draw. Draw opens a preview; Add to board makes native editable shapes only after review.

On the mock board, the preview contained Browser → API. Add created two nodes and one arrow, and a hard reload kept the three native shapes. The screenshot is evidence of the review and insertion interface, while the source of the answer was a mock responder.

Pasting a recognized Mermaid flowchart, SQL schema, OpenAPI JSON or short arrow chain routes through the same preview. Ordinary text continues through the native paste path. The MCP tools can stage SQL and OpenAPI proposals for the same explicit review step.

Feature surface

Editable diagrams

Eight starters now cover flowchart, mind map, ERD, sequence, architecture, API stack, data model and request flow. Connect makes bound native arrows; eligible graphs offer Arrange with undo. Personal blocks remain browser-local.

Developer inputs

OpenAPI JSON and SQL schemas can create reviewable maps; Mermaid import/preview and safe diagram paste share that review pattern. The Files menu downloads native .tldr; import accepts .tldr and legacy native .json. A sampled .tldr download → new-room import → reload preserved 3 labeled shapes. Conversion is deliberately bounded.

Boards and navigation

The refreshed dashboard gives Quick search and collections a left rail, with a clear Start drawing action and larger recent-board previews. It keeps inline rename, bulk move, recoverable Trash, direct room links and page search. Safari checks covered desktop and 720px.

Files and slides

Files downloads native .tldr and PNG/SVG, and imports .tldr, legacy native .json and bounded Excalidraw v2 with omission reporting. Excalidraw export is no longer in the UI. The slide organizer supports create, rename, order and start; the remote navigation and laser toggle passed a Safari↔Helium check on isolated empty frames.

Presentation stage

The stage renders frame contents without borders, has right-side hideable controls and a white/blue laser, and relays a scoped remote across browser profiles. Safari and Helium synchronized slide navigation and laser toggle. Content-slide fitting, first-frame paint and trail timing still need direct visual proof.

Local account and agents

The first local owner explicitly claims existing boards during setup. Password sessions gate board APIs, sockets, assets and AI routes. The signed-in dashboard offers sign-out and scoped revocable agent tokens; the MCP client can use one token without bypassing diagram review. The actual local workspace awaits owner setup.

Application text

Geist Sans is used for dashboard and application controls; handwritten canvas text remains separate. The dashboard is visibly checked, while a full cross-panel audit is still open.
